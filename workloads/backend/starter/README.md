# Your Backend Workspace

This project is already wired to the PostgreSQL and Redis services provisioned for your environment.

Start by editing `app/main.py`. The FastAPI server reloads automatically when you save.

Useful links are shown in the Student Platform:

- **Open Workspace**: browser VS Code
- **Open Application**: your running FastAPI service
- **API Docs**: append `/docs` to the application URL

The platform injects the database and Redis connection settings for you. You do not need to configure Kubernetes, Docker, service discovery, or secrets.
